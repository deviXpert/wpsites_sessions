## ⚠️ Before doing anything in a new session
1. Credentials come from env vars only: `WP_URL`, `WP_USER`, `WP_APP_PASSWORD` (or `BB_WP_*`). Never paste them in chat.
2. `tools/wp.py` **refuses to run unless the host is `papayawhip-ostrich-717285.hostingersite.com`** (override with
   `BB_EXPECTED_HOST` only if the site moved). Other clients (AAD, EHMC) live in this repo.
3. User rules: native Elementor widgets only; any extra CSS/JS goes in **Elementor → Custom Code** (never inline/HTML widgets);
   all images WebP. The user deleted all old pages before this build.
4. **Never** call `elementor/v1/documents/{id}/media/import` — it re-imports every image on the page as duplicates.

## How it is built
- Every document is generated by Python into classic Elementor JSON (flex/grid containers + native widgets) and written via
  REST meta `_elementor_data`, then `el.regen()` (MCP `elementor/update-page-settings`) rebuilds the CSS / element cache.
- `python3 build_all.py` (from `tools/`) rebuilds kit, menus, header, footer, popups, home and pushes Custom Code.
- Behaviour/visuals Elementor can't express natively live in `tools/bb.css` + `tools/bb.js`, pushed by `code.py` into two
  Custom Code snippets (site-wide). `code.py` also appends generated rules for Lucide SVG icon colours.
- Elementor quirks handled in `el.py`: widgets use `_css_classes/_position/_z_index`, containers `css_classes/position/z_index`;
  Elementor forces `--width:100%` and wrapping on mobile and 1-column grids on tablet/mobile, so widths/grids are mirrored
  explicitly; widths are `min(Npx, 100%)`.
- Kit (post 17, was "AutoWorks"; backup in `wp-backup/kit_17_autoworks.json`): Busy Bee colours, no default fonts,
  container padding 0, breakpoints mobile ≤767 / tablet ≤1023 (matches the design's md/lg).
- Fonts: Manrope (Google, via Elementor) + the design's system font stack (`--bb-sys`) for the sections that use it (`.bb-sys`).

## QA tooling (Node + Playwright, run from `tools/`)
- `node secs.js <width>` – section-by-section top/height vs the design (all 0 at 1440/1024; ≤14px at 768/390).
- `node textdiff.js <width> '<design sel>' '<live sel>' [px]` – every text node position/size/font vs the design.
- `node func.js` – functional test (hero slider, filters, popups, FAQ, forms, menus, links, WebP, no h-scroll).
