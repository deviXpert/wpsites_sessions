# Wassi Towing Ltd. — Website handoff package

Everything needed to build wassitowing.ca in WordPress + Elementor.

**Start here:** open this folder in Claude Code and say:

> Read CLAUDE.md and build the Wassi Towing website in WordPress + Elementor, starting with the Global Kit, header and footer.

- `CLAUDE.md` — the build spec (setup, page-by-page section map, interactions, SEO, acceptance checklist)
- `design/html/` — static HTML of every page and interactive state (open in a browser)
- `design/screenshots/` — desktop (1440px) and mobile (390px) full-page renders
- `content/website-content.md` — all copy, SEO titles, meta, H1s, keyword map and FAQs
- `brand/` — logos, favicons, design tokens
- `interactions/` — quote widget, Stranded mode, services filter, FAQ search, mobile sticky bar
- `seo/` — page meta + keyword sheet and JSON-LD schema

Items in [BRACKETS] are placeholders the client still has to confirm.
